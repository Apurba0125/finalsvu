Give it neither and the button is left off rather than pointing nowhere; the row still reads perfectly well as a record of the conference. doc wins if both are set, since a report is the more specific thing to open. WHY doc AND photo GO THROUGH doc_url Under the manifest storage a bare {% static %} raises for a file that was never collected, and one mistyped filename would take the whole page down. doc_url returns an empty string instead: the row falls back to a tinted placeholder for a missing photograph, and simply drops the button for a missing report. It also means both can be named here BEFORE the files are uploaded — each appears by itself once the file is in place and collectstatic has run: python manage.py collectstatic --noinput doc_url is a template builtin (settings.py registers svu_extras), so there is nothing to load for it. A full URL or a rooted path is handed straight back, which is why the same slot takes either. rel="noopener" is not optional alongside target="_blank": without it the opened tab can reach back through window.opener and navigate this one. {% endcomment %}
