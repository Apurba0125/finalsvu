{% load static %} {% comment %} Inner-page banner. Views supply: hero_title, hero_subtitle, hero_image, crumbs. hero_image GOES THROUGH doc_url, NOT {% static %}, for two reasons: It takes either form. Some views hand over a bare path out of data.py ("img/schools/soe.png") and others a path already resolved to /static/...; doc_url resolves the first and hands the second straight back, so a caller cannot get it wrong. A missing file costs the picture, not the page. Under the manifest storage {% static %} RAISES for a file that was never collected — one bad filename in data.py and every page using this banner is a 500. doc_url returns "" and the {% if %} below simply leaves the banner on its plain dark ground. Loaded eagerly, not lazily: this is the first thing on the page, and a lazy banner pops in after the text has already painted over it. {% endcomment %}
