    . Expects: name the department, worded exactly as it should read on the bar slug a short lowercase name with hyphens, e.g. "civil-engineering". It does TWO jobs, so it has to be unique on the page: 1. it builds the ids that wire each bar to the panel it opens 2. it names the folder the PDFs are read from years and months come from the view — they are a calendar, not content, so they are not repeated on every line. WHERE THE PDFs GO Every month reads one file, and the path is worked out rather than typed: static/documents/newsletter//-.pdf so for January 2024 of the department above: static/documents/newsletter/civil-engineering/2024-january.pdf Name the file that way, run python manage.py collectstatic --noinput and that month turns from "Not published" into a View link by itself. NOTHING IN THE TEMPLATE CHANGES — the whole page is driven by where the files sit. A month with no file stays on the list, so a year always reads as a complete twelve. The path goes through doc_url, so a folder that does not exist yet costs nothing: it resolves to an empty string and the month shows as unpublished. A bare {% static %} tag would raise instead and take the whole page down. THREE LEVELS, ONE CONTRACT Both bars are the same .nl-bar on the site's shared accordion — initAccordions in main.js, the same one behind the FAQ. Per bar it is aria-expanded for the state and aria-controls naming the panel, and the panel carries hidden so it is shut before any script runs. That pair is all that nests them: nothing counts levels, so a department can be dropped anywhere in the list. Every panel is shut on load. A department opens its years; a year opens its months. Opening one leaves the others alone. {% endcomment %}
