Order on the page is the order of the lines; the grid reads ACROSS then down, three to a row on a desktop, and nothing is sorted. WHAT View More OPENS The same doc= slot takes either kind of destination, and nothing has to say which it is: a PDF doc="documents/e-resource/jstor.pdf" Put the file in static/documents/e-resource/ and run python manage.py collectstatic --noinput the site doc="https://www.jstor.org/" A full address is handed straight through untouched. A filename can be written BEFORE the PDF exists — the link appears by itself once the file is uploaded. A mistyped one leaves that card reading "Link to follow" rather than taking the whole page down, which is what a bare {% static %} tag would do under the manifest storage. NONE OF THE CARDS BELOW CARRY A doc= YET, so every one of them reads "Link to follow" so far. Add doc= to a line as each PDF or address is settled. Every link opens in a new tab with rel="noopener", which matters more here than anywhere else on the site because most of these leave for somebody else's server. WRITE AN AMPERSAND AS & — a quoted string in a template tag is marked safe by Django, so what is typed between the quotes lands in the page verbatim. A bare & is not valid HTML and misparses next to a word. That is why the Taylor & Francis line below is written the way it is. NOTE ON COMMENTS: the hash-style Django comment {# … #} covers a SINGLE line.
