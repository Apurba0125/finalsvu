Do not add them here. THIS PAGE IS WRITTEN BY HAND It is not built from NOTICES in data.py. Edit the cards below directly. NOTICES still feeds the small board on the home page, so a notice that should appear in both places has to be written in both. That is the trade for being able to lay a notice out however it needs to be here. There is no page per notice. Anything still pointing at an old /notices// address redirects here. TO ADD A NOTICE Copy one "notice card" block and edit it. Newest first — nothing sorts these for you. Two across on a wide screen, one on a phone, so an even number of cards never leaves a gap beside the last one. The pieces of a card: is-important on the article turns the left spine red notice-card__date the date line notice-item__flag the red NEW badge notice-card__text an optional line under the title; drop the whole

for a card that is title only notice-card__foot the download button; drop the whole

when there is nothing to download TO ATTACH A PDF 1. Put the file in static/documents/ 2. Uncomment the notice-card__foot block in that card and put the real file name in 3. Run: python manage.py collectstatic --noinput Not optional once DEBUG is off. WhiteNoise's manifest storage raises ValueError for a path it never collected, so a missing file takes this page down rather than giving one dead link. The home board resolves its paths forgivingly through the view; a bad path written HERE is fatal, because there is no view in between to catch it. NOTE ON COMMENTS: the hash-style Django comment covers a SINGLE line.
