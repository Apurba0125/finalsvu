NOTICES still feeds the small board on the home page, so a notice that should appear in both places has to be written in both. That is the trade for being able to lay a notice out however it needs to be here. There is no page per notice. Anything still pointing at an old /notices// address redirects here. TO ADD A NOTICE Copy one "notice card" block and edit it. Newest first — nothing sorts these for you. Two across on a wide screen, one on a phone, so an even number of cards never leaves a gap beside the last one. The pieces of a card: is-important on the article turns the left spine red notice-card__date the date line notice-item__flag the red NEW badge notice-card__text an optional line under the title; drop the whole

for a card that is title only notice-card__foot holds the Read More link; it draws itself only when the PDF named in the card exists TO ATTACH A PDF Every card already carries a Read More block naming the file it expects. 1. Name the PDF to match, or edit the name in the card to match the PDF 2. Put it in static/documents/ 3. Run: python manage.py collectstatic --noinput The link appears by itself once the file is collected; until then the card simply has no Read More on it. That is the doc_url filter doing the work. A bare static tag raises ValueError for a path that was never collected, which would take this whole page down over one missing PDF; doc_url returns an empty string instead so the if can hide the link and the page stands. NOTE ON COMMENTS: the hash-style Django comment covers a SINGLE line.
