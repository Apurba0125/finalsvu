WHERE THE DEPARTMENTS ARE WRITTEN In this file, one line each — not in data.py. That is the point of the page having its own template: a department can be added, reworded or moved between the two panels by editing the line, with no Python to touch and nothing to keep in step anywhere else. The two panels are deliberately separate lists rather than one list filtered twice. They do not hold the same departments, and the same department can appear in both with a different list of books behind it. TO ADD A DEPARTMENT Copy a line inside the panel it belongs to and change it: {% include "includes/book_row.html" with title="DEPARTMENT OF PHYSICS" doc="documents/books/physics.pdf" %} title the department, exactly as it should read. Nothing forces case, so the line is the only place the wording lives. doc optional list of books the row opens: put the PDF in static/documents/books/ and name it here. Use url= instead to send the row to a page on this site rather than to a document. A row with neither still appears, with its arrow faded, so the department list stays complete while the PDFs are being collected. Drop a PDF in, run python manage.py collectstatic --noinput and that row turns into a link by itself — no edit here. NONE OF THE ROWS BELOW NAME A FILE YET, so every arrow is faded so far. Add doc= to a line as each list of books arrives. Order is exactly as written. The grid reads ACROSS then down, two to a line on a desktop and one once a name no longer has room, so the first two lines are the first row, the next two the second, and so on. An odd count leaves the last row half empty, which is correct — nothing is reflowed to hide it. THE TWO PANELS The pills and panels are the site's shared tab script — initTabPanels in main.js — which finds them by the data-tabs attribute on the wrapper and the .tab-btn / .tab-pane classes inside it. Those names are a contract with the script: rename one and the panels stop switching. Everything else is free. Whichever pill carries is-active in the markup opens on load; without one the script falls back to the first. The ids only have to match between a button's data-tab-target and its panel, so a third panel is a matter of copying a button and a panel and giving the pair a new id. Two pills sit side by side down to the narrowest phone, so this page ships no mobile dropdown for them — unlike Academic Activities, which has five.
